Dividend Tax
Default withholding tax rate applied to new dividend entries (PSX default is 15% for filers, 30% for non-filers). Pre-fills the Add Cash Entry form — each dividend keeps the rate that applied to it, so changing this doesn't rewrite past entries.
%
Capital Gains Tax
Default CGT rate NCCPL withholds on a sell's realized gain (Pakistan's standard rate is currently 15% for active/filer taxpayers). Pre-fills the suggested CGT when you record a Sell — each sale keeps the amount that applied to it, so changing this doesn't rewrite past entries.
%
NCCPL Charge
NCCPL's per-trade clearing/settlement charge, as a % of trade value — this never appears on your broker's own trade-confirmation memo, only on CDC's ledger, so it has to be entered here. Pre-fills the suggested amount on a new Buy/Sell and a PDF import — each trade keeps the amount that applied to it, so changing this doesn't rewrite past entries. Check a recent CDC customer ledger for your actual rate.
%

Backup
A full JSON snapshot of both stocks and mutual funds - transactions, cash ledger, settings, funds and fund transactions. Restoring re-adds every record through the same validated endpoints as adding them by hand, so it can't corrupt existing data - but re-imported stock buys/sells don't re-touch free cash (same as a bulk/PDF import), so restoring onto an account that already has cash entries will double them unless you clear cash first.
Reference Data
The PSX stock list and the MUFAP AMC/fund directory (used by the symbol autocomplete and the "Add New Fund" picker) already refresh on their own - stocks on every page load, funds at least once an hour in the background. Use this only if you know something new was just listed and don't want to wait.
